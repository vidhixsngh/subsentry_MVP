# 🚀 Run AI Analytics NOW

## Quick Commands

### 1. Install Dependencies
```bash
npm install recharts @google/generative-ai react-markdown date-fns
```

### 2. Restart Server
```bash
# Press Ctrl+C to stop current server
npm run dev
```

### 3. Open Analytics
- Go to http://localhost:5000
- Click "View Analytics" or navigate to /analytics

---

## What You'll See

1. **AI Insights Card** (top)
   - Loading animation
   - Personalized insights from Gemini
   - Refresh button

2. **Summary Stats** (3 cards)
   - Monthly total
   - Paid subscriptions
   - Needs attention

3. **Summary Alert**
   - "This month you spent ₹X across Y subscriptions"

4. **Interactive Charts** (2 charts)
   - Pie chart (category distribution)
   - Bar chart (category comparison)
   - Hover for tooltips!

5. **Top 3 Subscriptions**
   - Highest cost subscriptions
   - Monthly equivalent amounts

6. **Least Used Subscription**
   - Based on usage patterns
   - Savings calculation
   - Gentle suggestion

---

## Test It

1. Add a few subscriptions if you haven't
2. Go to Analytics
3. Wait for AI insights to load (~3-5 seconds)
4. Click "Refresh" to regenerate insights
5. Hover over charts to see tooltips
6. Check if least used suggestion makes sense
